防火墙按分片放过之后，攻击者用重叠分片把载荷拼成了另一条指令：偏移按字节处理而不是按八字节单位乘八，拼接位置错位；重叠检测只比较起始偏移，部分重叠漏检；重叠时保留后到分片并覆盖写，攻击者可改写已到达内容；区间合并只合并相邻不合并相交，覆盖集合出现重叠；完整性判定只看末片到达，中间缺口被忽略；拼接按到达顺序而不是按偏移排序，乱序到达时字节序错；缺片时返回已到达部分而不是抛异常，上层拿到截断载荷；超时按到达时间但清理时重置计时，长连接永不超时；内存预算按分片个数而不是总字节，海量小分片可撑爆；批量重组复用同一缓冲，第二个标识命中第一个标识的分片。frag/_impl.py 是核心，tests/test_reassembly.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

运行方式
进入仓库根目录，执行：
    python -m pytest tests -q
首轮预期为 15 failed，且无 error。修复过程中测试文件不得修改，验收仍以 tests/test_reassembly.py 的 15 条断言为准。

修复提示
